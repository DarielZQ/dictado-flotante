Dictado Flotante

Dicta en cualquier campo de texto de la web.

El botón no puede aparecer en las webs porque falta el permiso de acceso a los sitios.

1. Servicio de transcripción

Por defecto se usa el plan gratuito de Groq. Crea una clave en console.groq.com → API Keys y pégala aquí.

Avanzado: otro proveedor compatible con OpenAI

2. Micrófono

Concede el acceso una vez y marca «Recordar esta decisión». Así el dictado funciona en cualquier web sin volver a preguntar.

3. Dictado

«Español + Inglés» transcribe tal cual lo que digas aunque mezcles los dos idiomas, sin traducir. También puedes cambiar el idioma con clic derecho en el botón flotante o desde el icono de la barra.

4. Probar dictado

Graba una frase y el resultado aparecerá aquí abajo.

5. Sitios ocultos

    No hay sitios ocultos.

    Atajo de teclado

    Alt+Mayús+D empieza o detiene el dictado; Esc lo cancela. Puedes cambiar el atajo en about:addons → engranaje → «Administrar atajos de extensiones».
